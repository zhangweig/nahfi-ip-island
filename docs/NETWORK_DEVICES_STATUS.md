# 电脑状态、设备提醒与 IP 路由（0.6.52）

## 已实现

- 新增第 11 个同级功能页“电脑状态”。CPU、内存、网卡合计速率每两秒后台采样，磁盘容量每 30 秒刷新；不枚举进程或读取文件内容。网速汇总可能包含虚拟网卡重复流量。
- 新增低电量通知：默认阈值 20%，可配置 5%–50%，在设置 → 设备与 IP → 键鼠电量修改。有效低电量首次提醒一次，休眠/未知/断开不清除提醒锁；恢复至阈值以上 5% 后重新启用。通知遵从已有通知总开关。
- 新增自动系统代理路径，保留系统路由/TUN与手动代理端口。已有手动端口配置不会被覆盖。
- 网络接口地址或系统代理变化时清除旧结果，忽略旧路径的在途请求并重新检测。IP 页显示时最长 10 秒发起一次定期检查，请求本身有超时；切换全局/TUN后不一定换出口 IP，因此不伪造模式变化或国家变化。
- 标准 HTTP 缓存禁用请求头，减少复用缓存；继续后台请求、默认打码和手动显示/复制。

## IP 数据源

用户选择重新挑选数据源后，本版采用 Cloudflare Trace 主源与 ipwho.is 备用，替代此前待确认的网页地址。结果标注实际来源，不混合不同来源的 IP 与国家，主源成功不请求备用源；切换源保持同一路径，不会从指定代理降级直连。

Cloudflare 使用 `ip` 和 `loc` 字段，忽略数据中心 `colo`，避免把机房位置当成出口国家。429 按秒数或日期形式的 Retry-After 进入冷却，错误响应正文不显示。

来源依据与验证边界见 [IP 数据源说明](IP_SOURCES.md)。
