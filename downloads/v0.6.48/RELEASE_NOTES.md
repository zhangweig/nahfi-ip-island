# Nahfi IP Island v0.6.48

## 本版改动

1. 新增“键鼠电量”功能页，与音乐、专注、饮水等同级。显示已连接蓝牙键鼠的名称、电量百分比及电量条，每两秒更新。未知电量明确标示，支持多设备分页。
2. IP Monitor 移入同级功能页，不再覆盖主页面，也不占用收起药丸。完整 IP 默认打码；主动显示后 10 秒自动隐藏，切页或收起时隐藏，复制完整 IP 使用独立按钮。
3. 自动结合屏幕分辨率和 Windows DPI 缩放，4K / 100% 自动放大至约 2×，4K / 200% 避免重复放大。设置 → 常规可手动设置额外缩放。
4. 保留旧页面顺序与开关，新页面自动追加。Windows 版本信息及更新包格式升级到 0.6.48。

## 使用

下载 EXE 直接启动，或完整解压 ZIP 后运行其中的 daozai.exe。先退出旧版，再运行新版。
通过左右箭头、滚轮或底部页码切换功能页。页面开关、排序在设置 → 页面管理。
IP 页右上角设置可指定本机 HTTP/mixed 代理端口，0 为不指定代理。

## 支持范围与验证

- 键鼠电量依赖 Windows 蓝牙上报，USB 2.4G 接收器暂未适配。
- Linux 自动化测试覆盖 1×–3× DPI 下页面交互、IP 隐私、配置迁移和键鼠数据变化；两个原始上游已复现的 Linux 失败用例单独排除。
- Windows x64 GNU 交叉编译；验证 PE 格式、图标/版本资源和系统 DLL 导入。尚未进行 Windows 实机验证。
- IP 查询仅代表 ipwho.is 的请求出口；代理失败不回退直连。
