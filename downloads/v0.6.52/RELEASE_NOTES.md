# Nahfi IP Island v0.6.52

## IP Monitor

- Cloudflare Trace 主源，ipwho.is 备用，可在设置中锁定单一源，页面显示实际来源。
- 自动跟随系统代理、系统路由/TUN、指定本机代理三种方式。监测代理/网卡变化，旧路径结果失效后重新查询。
- 同一路径切换数据源，代理失败不回退直连；限流时按 Retry-After 冷却。
- 保留默认打码和手动显示/复制。全局和 TUN 若使用同一个出口，IP 可以不变。

## 键鼠和电脑状态

- 低电量提醒默认 20%，可设 5%–50%；每设备提醒一次，恢复后重新启用，未知/休眠不反复弹窗。
- 扩展迈从 A7 V2 Ultra+ / G87 V2、ATK F1 / A9 / X1 / Zero、VXE MAD R、VGN F1 / F2 等白名单接口，仍需实机验证。
- 新增同级电脑状态页：CPU、内存、网卡合计速率与磁盘剩余空间。

先退出旧版再启动。页面开关和顺序会迁移，新电脑状态页追加在末尾；低电量提醒在设置 → 设备与 IP → 键鼠电量中配置。

Windows x64 交叉编译。自动化测试覆盖本地协议、模拟请求、代理路径与 UI；当前云环境未完成所选数据源的公网访问测试，未验证用户实际硬件/TUN。详情见 docs/IP_SOURCES.md 和 docs/NETWORK_DEVICES_STATUS.md。
