# Nahfi IP Island v0.6.49 — USB 接收器实验性适配

针对用户的 KZZI K75 Lite 键盘和 VXE R1 鼠标，增加已知 2.4G 接收器的厂商 HID 电量读取。

- K75 Lite：匹配 3554:FA09，核对型号身份后查询在线状态与电量。
- VXE R1 系列：匹配 3554:F58A / 373B:1085，校验响应和电量范围。
- 每 15 秒后台刷新；无响应、休眠或驱动占用时显示未知，不当作 0%。
- USB 数据独立于蓝牙服务，不触发蓝牙连接通知。
- 保留上一版的独立 IP 功能页、隐私打码、4K/DPI 自动及手动缩放。

请退出旧版和官方键鼠驱动，唤醒键鼠后运行新版，等待 15 秒查看“键鼠电量”。

实验性说明：没有在用户实物上验证。K75 Lite 的参考项目仅确认连接检测，电量查询需实测；VXE 各子型号和固件不保证通用。若显示未知，请反馈接收器 VID/PID，无需序列号。

测试覆盖白名单、请求报文、分包、校验和、异常值和 UI 状态；Windows x64 交叉编译，不代表实机验证。协议来源和许可见 docs/USB_BATTERY.md。
