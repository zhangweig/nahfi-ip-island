# Nahfi IP Island v0.6.47-ip.1

基于岛仔 Daozai 0.6.47，新增 IP Monitor：

- 常规药丸显示本地 SVG 国旗和国家代码。
- 展开显示公网 IP、国家、代理查询路径及检测时间，支持复制和手动刷新。
- 可配置本机 HTTP / mixed 代理端口与刷新间隔；后台请求不阻塞动画。
- 代理失败不回退直连，历史结果标记为旧数据。

Windows x64 便携版：下载 EXE 可直接启动；ZIP 另含使用说明和许可证。
在 IP Monitor 设置中填写代理端口，例如 7890；0 表示不指定代理。
检测结果仅代表访问 ipwho.is 时的出口，不代表所有网站。

此构建使用 Linux 交叉编译 Windows GNU 工具链，已验证 PE 格式、图标资源和 DLL 导入；未进行 Windows 实机运行验证。
Linux 编译和新增功能测试通过；全量测试有两项在原始上游同样失败，排除后其余 389 项通过、24 项忽略。
